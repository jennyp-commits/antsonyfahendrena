# antsonyfahendrena
Projet Bibliothèque Théologique en ligne en Malagasy - C'est un application web et mobile qui permet à un utilisateur d'acheter et lire des livres. On s'en sert facilement de paiement via Mvola. Puis on aura notre propre bibliothèque numérique en ligne. Acheter facilement et lire tranquillement.
